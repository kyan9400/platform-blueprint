# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private security advisory flow and include the affected manifest, reproduction steps, and suggested mitigation. Reports are acknowledged within seven days.

This repository is a reference platform. Review every cluster, network policy, admission rule, and cloud variable against your own threat model before using it outside a lab environment.
